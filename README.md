# Blog Application
A Blog application using React.js, Python FastAPI, PostgreSQL, and LLM integration using OpenAI API Key

## Technology Stack

**Frontend:** ReactJS  + React Router
**Backend:** Python FastAPI + SQLAlchemy
**Database:** PostgreSQL
**LLM:** OpenAI API

## Project structure

```
blog-app/
├── backend/          # FastAPI + PostgreSQL + OpenAI
└── frontend/         # ReactJS
```
